# Suspicious Login Investigation
This project simulates a SOC investigation of suspicious authentication activity.
## Scenario
A user account experienced multiple failed login attempts from the same source IP address, followed by a successful login.

## Investigation
The activity was reviewed to identify:
- Repeated failed login attempts
- Successful login correlation
- Potential brute-force activity
- Severity level
- Recommended incident response actions

## MITRE ATT&CK
T1110 – Brute Force

## Tools Used
- Microsoft Excel
- Windows authentication event IDs
- MITRE ATT&CK
